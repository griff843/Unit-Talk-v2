## Objective

`close-eligibility-preflight.yml` and two `proof-gate.yml` jobs, Runtime Verifier Gate and T1 Proof Gate, find the lane by matching `(utv2|uni)-[0-9]+` or `utv2-[0-9]+` in the PR branch. A WORK-### branch never matches, so each gate logs a skip and reports success without evaluating the lane. On #1802, a T1 WORK lane:

- Runtime Verifier Gate logged `No issue ID in branch — skipping.`
- Close eligibility logged `resolves to no lane issue id; not a lane PR, skipping.`

Four WORK lanes needed repair after merge because their post-merge closeout failed on a proof rule (runs 40511401436, 40527619667, 40199729553 and 39759694166). Replaying `evaluateCloseEligibilityPreflight` against each PR's merged head blocks on the rule that closeout later failed on:

- WORK-2026102701 (#1789): P14
- WORK-2026102703 (#1792): P13
- WORK-2026102305 (#1779): P12 and P14
- WORK-2026102001 (#1770): P12

The two `proof-gate.yml` branch steps also substitute `${{ github.head_ref }}` and `${{ github.event.pull_request.head.ref }}` directly into the shell script, a branch-name script-injection pattern.

## Acceptance Criteria

- The branch-resolve steps of `close-eligibility-preflight.yml` ("Evaluate close eligibility") and `proof-gate.yml` ("Detect issue ID", "Extract issue ID") match `(utv2|uni|work)-[0-9]+`. Executed with bash as written, they resolve WORK-, UTV2- and UNI- branches to their lane id and resolve a branch with no id to a skip.
- Those two `proof-gate.yml` steps read the branch from `env:`; no `${{` remains in their `run:` scripts.
- The proof-auditor job's proof-dir match covers `(utv2|uni|work)`.
- The regression test in `scripts/ops/workflow-hardening.test.ts` fails when any one of the three branch matches is reverted, or when template substitution is restored.
- Unchanged: which checks are required (Close Eligibility stays advisory), Merge Gate, ERV, lane admission and PR file reservation. Also unchanged: the disabled `t1-proof-gate.yml` and `runtime-verifier-gate.yml`, and the other branch-resolving workflows.
