# WORK-2026110308 — pin Playwright jobs to ubuntu-24.04

Tier: T1
Lane type: hygiene
Executor: claude

Source: staging/CI reliability lane (Operating Claude), 2026-11-03.

Tier is T1 because preflight PE2 sets a mechanical T1 floor for any `.github/workflows/**` path. The change itself only moves four non-required jobs back to the runner image they last passed on.

## Objective

GitHub's `ubuntu-latest` label now resolves to `ubuntu-26.04`. qa-fast run 41692903141 logged `Image: ubuntu-26.04`, version 20261025.179. The repo pins `playwright` 1.58.2, which refuses that OS: `playwright install chromium --with-deps` fails with "Playwright does not support chromium on ubuntu26.04-x64". The last green qa-fast was 41518733002 on 2026-11-02, before the label moved. Every job that installs Playwright now fails at install, before any test runs.

Pin those jobs to `ubuntu-24.04`, the image they last passed on, so the existing tests run again.

## Acceptance Criteria

- `runs-on: ubuntu-24.04` on exactly the jobs that run `playwright install`:
  - `.github/workflows/qa-fast.yml` (job at :14);
  - `.github/workflows/qa-experience-regression.yml` (:16);
  - `.github/workflows/post-merge-qa-gate.yml` (:41);
  - `.github/workflows/staging-db-proof.yml` (the job at :47, which installs at :175).
- No other line changes: no step, trigger, permission, environment, secret, concurrency or test change, and no Playwright version change.
- qa-fast on this PR's head reaches and passes the Playwright install step.
