## Objective

The real Smart Form Track Only pilot on 2026-09-28 failed its acceptance contract. Pick `c12f1e2f-56d9-454b-9fd6-d9a3c0af4eb5` was submitted by `griff843` with `metadata.distributionMode: 'track-only'` ("Requesting Track Only"). The server persisted it as `delivery-eligible`, moved it to `queued`, and inserted a `discord:official-picks` outbox row (`5005f461`). Only the `official-picks` kill switch prevented member delivery.

Root cause: `apps/api/src/handlers/submit-pick.ts` (UTV2-1923) refuses any capper value except `track-only`, then OVERWRITES `distributionMode` from the server allow-list. An allow-listed capper therefore cannot submit Track Only at all, and the Smart Form "delivery eligible" choice is refused with 403.

## Acceptance Criteria

- An authenticated capper's explicit `track-only` request persists as `track-only`, with zero outbox rows, zero receipts and no `queued` transition, even when the capper is on `UNIT_TALK_HUMAN_CAPPER_DELIVERY_ALLOWLIST` with the posture enabled. The authorization record says delivery was not authorized, and says why (`track-only-requested`).
- The exact production request shape of pick `c12f1e2f` is reproduced in a test that fails on `main` and passes after the change.
- A capper submission that declares no `distributionMode` is Track Only (fail closed). Delivery needs an explicit request.
- An explicit `delivery-eligible` request from an authorized capper follows the existing human-capper delivery path unchanged: server-authored authorization, per-capper routing, kill switch, target registry and exactly-once enqueue.
- An explicit `delivery-eligible` request from a capper the server does not authorize is refused with 403 `CAPPER_TRACK_ONLY_REQUIRED`, and nothing is persisted.
- Client-supplied authorization records are still destroyed on every source.
- A mutation drill that restores the widening turns the regression test red.
- A live staging proof shows persisted Track Only truth and zero outbox rows for an allow-listed capper's Track Only request against real tables.
