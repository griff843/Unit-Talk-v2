# WORK-2026101403 — UTV2-1954 unsupported-sport fixture must not depend on a WNBA catalog row

Tier: T2
Lane type: runtime
Executor: codex

Repo-owned work order (tracker independence). Test-only. No runtime, migration, scoring or production change.

## Objective

`apps/api/src/t1-proof-utv2-1954-promotion-replay.test.ts` (live-DB case "a game line and an unsupported sport replay at their recorded scores", ~line 220) uses `'WNBA'` as its unsupported-sport fixture. WNBA is becoming a governed sport (catalog migration `20261010170100`, runtime lane WORK-2026101402 / PR #1755). Once the runtime derives `sport_id = 'WNBA'`, this fixture writes a `picks.sport_id` that is absent from any DB without that migration (staging today), and fails at `picks_sport_id_fkey` (staging run 38557281798). The test's intent is "a sport the scoring model does not support is capped at 60 and replays at its recorded score", not WNBA specifically.

## Change

Replace the fixture sport `'WNBA'` / `'wnba-moneyline'` with a sport string that (a) the scoring model does not support and (b) `deriveSportId` (`packages/db/src/pick-foreign-keys.ts`) maps to no canonical sport id (so `picks.sport_id` stays NULL, as it did for WNBA before). Use `'CURLING'` and rename the labels to `curling-moneyline`. Verify against the code that (a) and (b) hold and that the submission path accepts the string exactly as it accepted `'WNBA'` before. Keep the cap assertion (<= 60). Update any comment naming WNBA there. Do not touch any other file; confirm `promotion-edge-integration.test.ts`, `alert-agent-service.test.ts` and `canonical-reference-schema.test.ts` WNBA references are unaffected (read-only check, report).

## Acceptance Criteria

- The live-DB test passes against a DB that has NO WNBA sport row, and would pass unchanged against one that has it.
- The unsupported-sport cap assertion is retained.
- `pnpm exec tsx --test apps/api/src/t1-proof-utv2-1954-promotion-replay.test.ts` runs (live-DB cases skip locally by guard; report that honestly); type-check and lint exit 0.
- Mutation check by reasoning or run: replacing the sport with `'NBA'` would make the cap assertion fail.
