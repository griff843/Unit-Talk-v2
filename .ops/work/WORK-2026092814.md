# WORK-2026092814 — The Discord bot promises only what is live

Tier: T2 · Lane type: delivery-ui (app: discord-bot) · Executor: claude

Repo-owned work order (tracker independence, ratified 2026-09-05). No Linear issue exists for this identity by design.

Required reading: `docs/03_product/MEMBERSHIP_PRODUCT_CONTRACT.md` §3.1 (a capability is not advertised as live because code exists), §4.3–§4.4, §5, §7 (missing evidence renders as unavailable).

## Objective

Member-facing bot copy states no capability that is not live. It removes or marks unavailable every false claim. It invents no tier name, price or new promise.

## Why

`docs/mission/plan.md` §4.2 records copy that promises what is not live. Every governed delivery target except `official-picks` is killed, and market data is parked with SGO:
- VIP is told it has Best Bets;
- VIP+ is told it has Trader Insights;
- `/heat-signal` implies line movement is being monitored;
- recap and stats label CLV "vs SGO close" while CLV is null on every settled pick.

## Acceptance Criteria

- `trial-status.ts` / `upgrade.ts`:
  - VIP is described by what it gets today: official capper picks, recaps, results and the capper board.
  - VIP+ is described as everything in VIP, with its market-intelligence features "not live yet".
  - No "Best Bets" or "Trader Insights" claim remains.
- `heat-signal.ts`: the command description and empty state say line-movement alerts are not live yet. They do not imply that monitoring is running.
- `recap.ts` / `stats.ts`: the CLV display label drops "vs SGO close". A missing CLV renders as "unavailable", not as `—` and not as zero. API field keys are read unchanged.
- The existing bot tests are extended (no new test file; `package.json` is held by another lane's lock) to assert:
  - the absence of each removed claim;
  - the "unavailable" rendering.
- Scope: `apps/discord-bot/**` only. No worker, API, website or delivery change. Tier names and prices are unchanged; they are Griff's.

## Exit Criteria

- PR merged on green CI per the Merge Gate's T2 path, then closed through `post-merge-lane-close.yml` without `pr`.
- The proof names `pnpm type-check`, `pnpm test`, `pnpm verify` and `scripts/ci/r-level-check.ts`.
