# SGO Reactivation Gate

**Status:** Active checklist — WORK-2026092101
**This document authorizes nothing.** SGO activation is reserved (paid provider commitments and
secrets, `docs/mission/intent.md` reserved decisions 3 and 4) and is currently **owner-deferred**:
per the standing sequencing directive of 2026-09-18, SGO stays intentionally off until all
meaningful provider-independent work is exhausted. Nothing here re-raises that decision.

What this document is: the checklist that must be **true and demonstrated** before PM should
authorize heavy ingestion across NFL, NCAAF, NBA, NCAAB, NHL, MLB, player props, player stats and
team stats. It exists so that when the deferral ends, the question is a decision rather than a
project.

Each item states the artifact that closes it. An item closed by a recollection is not closed.

## G. The open question that must be answered first

**Does a reactivated ingestor write into `provider_offers_legacy_quarantine`?**

`apps/ingestor/src/write-surface.ts` maps four provider-offer writes to the logical name
`provider_offers`, and `public.provider_offers` is a view over the quarantine relation
(`FIRST_ARCHIVE_CANDIDATE_PACKET.md` §2). If that view is auto-updatable, heavy ingestion would
pour volume into the relation everyone is treating as frozen legacy.

This is read-only to answer and is **UNMEASURED** — production was `RESTORING` for this lane:

```sql
SELECT is_updatable, is_insertable_into
FROM information_schema.views
WHERE table_schema = 'public' AND table_name = 'provider_offers';
```

No coverage estimate, storage projection or retention plan in this document is sound until it is
answered.
